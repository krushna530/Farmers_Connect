# 🌾 Farmers Connect

🌱 **Farmers Connect** is a web-based platform designed to support farmers by providing
a digital space to **connect, communicate, and gain expert guidance** on agricultural
topics. The platform bridges the gap between farmers and experts through blogs,
open discussions, and a dedicated query system.

---

## ✨ Features

- 📝 **Dedicated Blog Section**
  - 📚 Agriculture-related blogs and articles
  - 🌾 Helps farmers learn modern and effective farming practices

- 💬 **Open Chat Section**
  - 👨‍🌾 Farmers can communicate with other farmers
  - 🔄 Share experiences, farming tips, and solutions

- 👨‍🔬 **Expert Query Section**
  - ❓ Farmers can ask questions directly to agricultural experts
  - ✅ Experts provide trusted and practical solutions

- 🔐 **Admin Management**
  - 🛠️ Admin can manage blogs and expert responses
  - 🔒 Ensures controlled and secure content handling

- 📱 **Responsive Design**
  - 💻 Works on desktops
  - 📲 Optimized for mobile devices

---

## 🛠️ Tech Stack

- 🎨 **Frontend:** HTML, CSS, JavaScript, Bootstrap
- ⚙️ **Backend:** PHP
- 🗄️ **Database:** MySQL
- 🌐 **Server:** Apache (XAMPP)

---

## 🚀 Installation & Setup

1️⃣ **Clone the repository**
git clone https://github.com/krushna530/Farmers_Connect

2️⃣ **Move project to XAMPP htdocs**
C:\xampp\htdocs\

3️⃣ **Create Database**

- 🧩 Open phpMyAdmin

- 🆕 Create database fm_db

- 📥 Import the provided .sql file

4️⃣ **Start Services**

▶️ Start Apache

▶️ Start MySQL

5️⃣ **Run the Project**

http://localhost/farmers_connect
